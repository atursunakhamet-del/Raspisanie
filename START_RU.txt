OQU: ЛИЧНЫЕ КАБИНЕТЫ УЧЕНИКА И ПРЕПОДАВАТЕЛЯ

Эта версия работает с сервером и общей базой данных. Теперь ученики и преподаватели могут входить со своими логинами и паролями, видеть общие расписания и переписываться.

КАК ЗАПУСТИТЬ НА КОМПЬЮТЕРЕ
1. Установите Node.js версии 24 или выше.
2. Распакуйте ZIP полностью. Откройте папку oqu-timetable в VS Code.
3. Откройте Terminal → New Terminal.
4. Введите: node local-server.mjs
5. Откройте http://localhost:5500.
6. В терминале появится First admin setup code. Скопируйте код.
7. На сайте выберите «Тіркелу» → «Әкімші», придумайте свой логин и пароль от 10 символов, введите скопированный код.

Для этого способа не нужно выполнять npm install. Терминал должен оставаться открытым. Данные сохраняются в .local-data; папку нельзя публиковать. Это локальный сервер для одного компьютера. Для доступа с разных устройств используйте опубликованный сайт.

ПЕРВЫЕ ДЕЙСТВИЯ АДМИНИСТРАТОРА
1. Заполните «Топтар», «Оқытушылар», «Пәндер», «Аудиториялар».
2. Добавьте уроки и задания. Если есть старый JSON-экспорт расписания, откройте его через «Ашу ↑». Для прежнего расписания в этом же браузере при пустой базе есть «Жеке кабинет → Бұрынғы кестені көшіру».
3. В «Жеке кабинет → Оқытушыны шақыру» выберите преподавателя, создайте код и передайте ему лично. Код используется один раз и действует 7 дней.
4. Преподаватель выбирает «Тіркелу → Оқытушы», вводит приглашение и создаёт собственные логин и пароль.
5. Ученик выбирает «Тіркелу → Оқушы», указывает свою группу и создаёт собственные логин и пароль. Группа должна быть создана заранее.

ПЕРЕПИСКА
В «Хат алмасу» выберите человека, напишите вопрос или ответ и нажмите «Жіберу». Оба участника должны быть зарегистрированы. У ученика в списке только преподаватели и администратор. Учитель видит зарегистрированных учеников.

Новые сообщения сохраняются в базе. У получателя появляется число на колокольчике и запись в «Хабарламалар». При открытом сайте проверка идёт каждые 12 секунд. Закрытый браузер не получает автоматический push; при следующем входе непрочитанные сообщения будут видны. Разрешение браузерных уведомлений можно включить отдельной кнопкой.

Ученик не может менять общее расписание. Выполнение домашнего задания отмечается отдельно для каждого ученика. Учитель и администратор могут менять расписание и задания. Изменения становятся видны ученикам их группы.

ЗАБЫЛИ ПАРОЛЬ
Администратор может в своём кабинете сбросить пароль ученика или преподавателя, подтвердив действие собственным паролем. После этого пользователь меняет временный пароль в своём кабинете. Для самого администратора автоматического восстановления по email нет — не теряйте его логин и пароль.

ВАЖНО О GITHUB
GitHub Pages не запускает сервер, аккаунты и базу данных. Открывать HTML двойным щелчком или через Live Server для этой версии недостаточно. На GitHub можно хранить исходный код, но рабочий сайт должен размещаться на серверном хостинге. Готовый опубликованный сайт указан в сообщении со ссылкой на проект; код первого администратора для него выдаётся отдельно и отличается от локального.

ПРОЕКТ
Интерфейс — HTML/CSS/JavaScript. Сервер — JavaScript; это не Java. Для публикации используются Vinext и SQLite/D1, для локального запуска — встроенные в Node.js средства. Описание проекта на казахском — PROJECT_KK.md. Проверки: node tests/accounts.test.mjs.
