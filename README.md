# Oqu — Сабақ кестесі және оқушымен байланыс

19-тақырыптағы курстық жобаның практикалық бөлігі. Интерфейс қазақша. Бұл нұсқа — ортақ дерекқоры және жеке аккаунттары бар толық веб-қосымша.

## Құрамы

- HTML/CSS/JavaScript интерфейсі, авторлық Oqu белгішелері.
- JavaScript сервері, жарияланған нұсқада Vinext + Cloudflare Workers + D1 (SQLite).
- Жергілікті компьютерде Node.js және SQLite арқылы тәуелділіксіз іске қосылатын сервер.
- Оқушы, оқытушы және әкімші рөлдері; логин және құпиясөз.
- Апталық кесте, нақты уақыт және қақтығыстарды тексеру.
- Үй тапсырмалары, жеке орындалу белгілері.
- Оқушы ↔ оқытушы жеке хаттары, оқылды күйі, оқылмаған хабарламалар және кесте өзгерісі туралы ескертулер.

Бұл жоба Java емес, JavaScript тілінде жазылған.

## Жергілікті іске қосу — ең оңай тәсіл

1. **Node.js 24 немесе одан жаңа нұсқасын** орнатыңыз.
2. ZIP архивін толық шығарып, `oqu-timetable` бумасын VS Code-та ашыңыз.
3. VS Code → Terminal → New Terminal.
4. Орындаңыз: `node local-server.mjs`.
5. Терминалдағы `http://localhost:5500` мекенжайын ашыңыз.
6. Терминалда көрсетілген **First admin setup code** кодын көшіріңіз. Сайтта «Тіркелу → Әкімші» таңдап, өз атыңызды, логиніңізді, кемінде 10 таңбалы құпиясөзді және сол кодты енгізіңіз.

Бұл тәсілде `npm install`, Java немесе жеке SQL сервері қажет емес. Node.js ішіндегі SQLite қолданылады. Терминалды жапсаңыз, сервер тоқтайды. Деректер мен жергілікті құпия баптаулар `.local-data` бумасында сақталады. Бұл буманы басқа адамдарға не Git-ке жібермеңіз. Ол архивке кірмейді.

`index.html` файлын жай ашу немесе Live Server жеткіліксіз: аккаунттар мен хаттар үшін сервер қажет. GitHub Pages сервер мен SQLite API-ін орындамайды. Репозиторийге бастапқы кодты сақтауға болады, ал жұмыс істейтін толық нұсқа серверлік хостингте орналасуы керек.

## Алғашқы баптау

1. Бірінші әкімші кабинетіне тіркеліңіз. Жарияланған сайттың бастапқы коды сайт иесіне бөлек беріледі; архивте жоқ. Бастапқы кодты оқушыларға таратпаңыз.
2. «Топтар», «Оқытушылар», «Пәндер», «Аудиториялар» тізімдерін толтырыңыз.
3. «Жеке кабинет → Оқытушыны шақыру» бөлімінде оқытушыны таңдап, бір реттік код жасаңыз. Код 7 күн жарамды. Оқытушы «Тіркелу → Оқытушы» арқылы өзінің логині мен құпиясөзін жасайды.
4. Оқушы «Тіркелу → Оқушы» арқылы оқу тобын таңдап, жеке тіркеледі. Оқушылар өз тобын өздері таңдайды; бұл нұсқада колледж тізімімен автоматты растау жоқ.
5. Сабақ пен тапсырма қосыңыз. Топтағы оқушылар оны өз аккаунттарында көреді. Сабақтар апта сайын дүйсенбі–жұма күндері қайталанады.

Ескі браузерлік нұсқаның кестесін жоғалтпау үшін бұрынғы сайттан JSON көшірмесін жүктеңіз. Әкімші немесе оқытушы жаңа сайтта «Ашу ↑» арқылы импорттайды. Ескі кесте осы мекенжайдағы браузерде сақталған болса, бос базада «Жеке кабинет → Бұрынғы кестені көшіру» батырмасы бар. Мұндай көшіру тек пайдаланушы батырманы басқанда орындалады. Аккаунттар мен хаттар JSON кесте көшірмесіне кірмейді.

## Хат алмасу және хабарламалар

«Хат алмасу» бөлімінен алушыны таңдап, сұрақ немесе жауап жіберіңіз. Екі жақтың аккаунттары сайтта тіркелуі керек. Хабарламаның жіберілген және оқылған күйі көрінеді. Ұзын әңгімеде «Алдыңғы хабарлар» батырмасы бар.

Хаттар мен оқылмаған хабарламалар серверде сақталады. Сайт ашық кезде жаңа хабарлар **12 секунд сайын** тексеріледі. Қоңырау белгісіндегі сан және «Хабарламалар» бөлімі жаңарады. Рұқсат берілсе, браузер жүйелік хабарлама көрсетеді. Браузер жабық кезде автоматты push немесе email жіберілмейді; келесі кіргенде оқылмаған хаттар көрсетіледі. Кесте не тапсырма өзгергенде, сол топтағы тіркелген оқушыларға хабарлама жасалады.

## Құпиясөз және сеанс

Құпиясөз ашық мәтін ретінде сақталмайды. Әр аккаунтқа кездейсоқ salt, PBKDF2-SHA256 (100 000 итерация) және серверде бөлек сақталатын HMAC pepper қолданылады. Итерация саны Worker платформасының шегіне сай таңдалған. Сеанс токені кездейсоқ жасалады, дерекқорда тек хэші сақталады. Cookie — HttpOnly, SameSite=Strict және HTTPS мекенжайында Secure. Сеанс 7 күнге дейін жарамды. Шығу оны жояды; құпиясөз өзгергенде басқа құрылғылардағы сеанстар тоқтайды.

Кіру мен тіркелуге сұрау жиілігінің шегі қойылған. Өзге сайттан өзгерту сұраулары қабылданбайды. SQL мәндері параметрлер арқылы беріледі. Хат мәтіні HTML ретінде орындалмайды. Әкімші ұмытылған құпиясөзді өзінің құпиясөзін растап қалпына келтіре алады; жаңа уақытша құпиясөзді пайдаланушыға жеке беру қажет.

## Серверлік хостинг және әзірлеу

Жарияланған нұсқа `.openai/hosting.json` ішіндегі `DB` D1 байланысын пайдаланады. `db/schema.ts` — схема, `drizzle/` — оның өзгермейтін миграциялары. Хостинг құпиялары: `AUTH_SECRET` және `SETUP_CODE`. Оларды бастапқы кодқа не браузерге енгізбеңіз. Жаңа орналастыруда жаңа ұзын кездейсоқ мәндер жасаңыз.

Vinext әзірлеу нұсқасы:

```sh
npm install
npm run build
# Жергілікті D1 миграциясын қолдану:
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_dashing_snowbird.sql
npm run dev
```

Бұл режимде `.dev.vars` файлына `AUTH_SECRET` және `SETUP_CODE` мәндерін жазыңыз. `.env.example` тек атауларды көрсетеді. Қарапайым көрсету үшін жоғарыдағы `node local-server.mjs` тәсілін таңдаңыз.

## Қазіргі шектеулер

Кесте қолмен жасалады; автоматты оңтайландыру жоқ. Жеке аптаға ауыстыру/ауыстырылған сабақ режимі, файл тіркеу, email, SMS, жабық браузердегі push, студент тобын әкімшімен растау және көпколледжді бөлек ұйымдар жоқ. Хаттар серверде сақталады, шеттен шетке шифрлау қолданылмайды. Жергілікті режимде бір компьютердің базасы, жарияланған нұсқада серверлік ортақ база пайдаланылады.

## БҚ-331 және БҚ-332 кестесі

«Расписание студентов  06.10.2026.xlsx» файлының Classes парағынан БҚ-331 (875–892 жолдар) және БҚ-332 (894–911 жолдар) кестелері енгізілген. Екі топ та 3-курс деп белгіленді. Барлығы 80 бастапқы сабақ ұяшығы; 1–8 және 9–16 апталарға бөлінген нұсқалармен 84 жазба сақталады. Әр сабақ — 45 минут; негізгі уақыттар: 08:00–08:45, 08:50–09:35, 09:40–10:25, 11:20–12:05, 12:10–12:55, 13:00–13:45, 13:50–14:35, 14:40–15:25. Қысқа үзілістер — 5 минут, үлкен үзіліс — 10:25–11:20 (55 минут).

Кестеде «Оқу аптасы» арқылы нақты семестр аптасын таңдаңыз. Файлда семестрдің басталу күні берілмеген, сондықтан алғашқы ашылуда ағымдағы күнге өздігінен апта нөмірі тағайындалмайды: бастапқы таңдау — 1-апта. Қолданушы таңдаған апта осы құрылғыда сақталып, келесі апталарға күн бойынша жылжиды. Аптаға тәуелді пәндер, еске салғыштар және күнтізбе экспорты сол таңдауды ескереді.

Бейсенбідегі G887 және D906 ұяшықтарында «Компьютерная графика 9-16» және екі оқытушы көрсетілген. Тек 9–16 апталарға сабақ енгізілді; екі оқытушы да сақталды. 1–8 апталар үшін файлда көрсетілмеген пән ойдан қосылмайды. Бірінші импорт бұрынғы БҚ-331/БҚ-332 сабақтарын осы дерекпен ауыстырады; өзге топтар мен тапсырмаларға тимейді. Бұрынғы ортақ кесте data_imports кестесінде сақтық көшірме ретінде сақталады. Импорт бір рет орындалады, кейінгі қолмен өзгерістерді қайталап үстінен жазбайды.

Жаңа тексерулер: `node tests/source-import.test.mjs`. Олар оқу апталарының қиылысуын, қосымша оқытушыларды, 80 бастапқы ұяшықтың толықтығын, үзілістерді, қолданыстағы идентификаторларды және импорттың бір реттік болуын тексереді.

## Корпоративтік пошта және тіркелу хабарламалары

Оқушының логині — `@college-narxoz.kz` доменіндегі корпоративтік пошта. Тіркелу кезінде домен серверде тексеріледі; кіруде регистр мен шеткі бос орындар қалыпқа келтіріледі. Жеке пошта және ұқсас бөтен домендер қабылданбайды. Бұл нұсқа пошта жәшігіне код жібермейді және жәшік иелігін растамайды: мұндай растау үшін колледждің SSO жүйесін немесе пошта жіберу қызметін бөлек қосу қажет.

Бұрын қарапайым логинмен тіркелген оқушыға әкімші «Жеке кабинет → Оқушының корпоративтік поштасы» арқылы мекенжай байланыстырады. Растау үшін әкімшінің қазіргі құпиясөзі қажет. Оқушының id, тобы, хаттары мен тапсырмалары сақталады, ал ескі сеанстары жабылады. Әкімші мен оқытушының бұрынғы логиндері жұмысын жалғастырады.

Әр сәтті оқушы/оқытушы тіркелуі әкімшіге «Хабарламалар» бөлімінде аты-жөні, пошта/логині және тобы бар жеке ескерту жасайды. Ол әкімші сайтта болмаса да сақталады. Пароль хабарламаға кірмейді. Жаңа тіркелу туралы email немесе SMS жіберілмейді.

Кіру, тіркелу, пароль өзгерту және қалпына келтіру формаларындағы көз белгісі парольді көрсетеді/жасырады. Өріс қателері сол өрістің астында беріледі; кірудегі қате жалпы болып қалады, өйткені парольдің қате таңбасын хэштен анықтау мүмкін емес. Аккаунттар бойынша автоматты тексерулер саны — 60.

## Әкімші құпиясөзін жеке сілтемемен қалпына келтіру

`/admin-recovery.html` беті сайт иесі шығарған уақытша, кездейсоқ токені бар жеке сілтемені қабылдайды. Токен URL фрагментінен алынып, мекенжайдан дереу өшіріледі; серверге POST сұрауында жіберіледі. Нақты токен кодта немесе браузердің тұрақты қоймасында сақталмайды.

Иесі тек Sites сервер баптауларында `ADMIN_RECOVERY_TOKEN_HASH`, `ADMIN_RECOVERY_USER_ID`, `ADMIN_RECOVERY_PASSWORD_HASH`, `ADMIN_RECOVERY_EXPIRES_AT` мәндерін орнатады. Бірінші мән — 32 байттық кездейсоқ токеннің SHA-256 хэші; үшінші мән — қалпына келтіру сілтемесі берілген сәттегі әкімші паролінің қолданыстағы сақталған хэші. Бұл мәндер бастапқы кодқа енгізілмейді.

Қалпына келтіру әкімші идентификаторына, мерзіміне және бұрынғы пароль хэшіне байланысты. Жаңа пароль атомдық салыстыру арқылы сақталады. Барлық әкімші сеанстары жабылады; пароль өзгергеннен кейін сол сілтеме қайта қолданылмайды. Токен мерзімі аяқталса да қабылданбайды. Қалпына келтіруде сабақ кестесі, аккаунттар, топтар, хаттар және тапсырмалар өзгертілмейді. 17 арнайы автоматты тексеру осы мінез-құлықты қамтиды.
